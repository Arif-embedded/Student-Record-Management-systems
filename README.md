# Student-Record-Management-systems
The Student Record Management System is a robust, menu-driven command-line application developed in C designed to efficiently manage student data using a singly linked list architecture. Built with a strong emphasis on clean code and modular programming principles, the project separates responsibilities into dedicated source modules (such as stud_add.c, stud_del.c, stud_mod.c, stud_show.c, and stud_save.c) governed by a centralized header file (student.h). It implements dynamic memory allocation (malloc, free) to manage student nodes in real-time, ensuring optimal memory hygiene, preventing leaks, and supporting robust file handling via student.dat for persistent data storage across sessions.
The application offers an interactive, continuous text menu providing comprehensive administrative controls. Core features include automatic unique roll number assignment, multi-criteria record searching and modification (by roll number, name, or percentage), tabular data rendering, and flexible sorting capabilities (alphabetically by name or in descending order by percentage). Additionally, the system supports advanced list manipulations—such as reversing node pointers in place, deleting specific or all records safely, and handling comprehensive input validation—making it an ideal implementation of advanced C data structures and file management concepts.
